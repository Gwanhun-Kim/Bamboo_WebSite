# BAMBOO Archive

세종대학교 사진동아리 BAMBOO의 메인 아카이브 화면입니다. 별도 빌드 과정 없이 정적 호스팅에 배포할 수 있습니다.

## 로컬 실행

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다.

## 구성

- `index.html`: 메인 페이지 구조와 콘텐츠
- `styles.css`: 데스크톱, 태블릿, 모바일 반응형 스타일
- `script.js`: 모바일 메뉴와 키보드 상호작용
- `assets/photos`: 프로젝트용 로컬 사진 자산
